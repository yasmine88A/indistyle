# IndiStyle — Boutique de vêtements indiens

Site e-commerce développé dans le cadre de mon projet de fin d’année de 3ᵉ année à l’EMSI.

## Fonctionnalités

- Présentation d’un catalogue de vêtements indiens.
- Consultation des fiches produits.
- Gestion du panier.
- Gestion locale des produits et des utilisateurs.
- Conservation des données dans le navigateur avec localStorage et JSON.

## Technologies utilisées

- HTML5
- CSS3
- JavaScript
- localStorage et JSON

## Lancement en local

1. Cloner le dépôt :

   ```bash
   git clone https://github.com/yasmine88A/indistyle.git
   ```

2. Ouvrir le dossier `indistyle` dans Visual Studio Code.

3. Lancer la page d’accueil avec l’extension **Live Server**.

## Stockage des données

Les données sont enregistrées dans le localStorage du navigateur.
Elles sont propres au navigateur utilisé et peuvent être effacées
en supprimant les données du site.

Ce projet est une démonstration front-end : le stockage côté
navigateur ne constitue pas une authentification sécurisée
pour une application en production.
